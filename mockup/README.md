# Макет интерфейса «ТКО | Мониторинг»

Отдельное приложение на выдуманных данных. С бэкендом не связано.

## Запуск

```bash
cd mockup
npm install      # один раз
npm run dev      # http://127.0.0.1:5190/
```

## Настройки макета

Кнопка «Настройки макета» в правом нижнем углу. Там меняются:
устройство (десктоп / телефон в рамке), тема, основной и дополнительный цвет,
вид боковой панели и меток статуса, подложка карты, шрифт, скругления,
плотность, анимации и состояние данных (загрузка, ошибка, пусто).
Зелёный цвет — только для статуса «Чисто», всё остальное — один голубой акцент.

Настройки запоминаются в браузере. Их можно задать и в адресе:

```
http://127.0.0.1:5190/?device=phone&theme=dark&primary=0EA5E9&accent=A3E635#/alerts
```

Кнопка «Скопировать токены» кладёт в буфер обмена CSS-переменные текущей темы —
для переноса во `frontend/`.

## Что где

- `src/theme.ts` — цвета, контраст текста, CSS-переменные
- `src/data.ts` — выдуманные площадки и оповещения (первые 8 — из `backend/app/seed.py`)
- `src/pages/` — экраны: вход, панель, карта, камеры, площадка, оповещения
- `src/modals/` — профиль, форма камеры, просмотр снимка
- `src/components/Frame.tsx` — настоящий кадр с камеры и рамки детекций
- `src/frames.json` — ответ прод-модели (`backend/app/ml`, три ONNX + ROI) на кадрах из `ml/demo_frames` и `ml/live_demo`
- `public/frames/` — сами кадры (уменьшенные копии). На них видны номера машин,
  поэтому папка в `.gitignore`, как и исходные `ml/demo_frames/`

## Полезные адреса

- `#/alerts/3` — оповещения с открытой панелью оповещения №3
- `?motion=false` — без анимаций и плавной прокрутки
